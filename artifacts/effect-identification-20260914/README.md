# Идентификация белого огненного круга

Источник воспроизведён: повторный `volatile-blast` от взрывающегося Землекопа (`digger`).

Воспроизведение использует штатный `step`, подготовленное ровное поле, одного врага, пустые руки и отключённые волны. Обычный рабочий за шесть секунд взрывается один раз и погибает. Землекоп самостоятельно начинает подземное перемещение, подходит на дистанцию запала, сохраняет `burrow/travel`, затем взрывается 224 раза и остаётся со 100 HP. Результат: `reproduction.json`; запуск: `node --import ./scripts/register-test-loader.mjs artifacts/effect-identification-20260914/reproduce.mjs`.

Цепочка ошибки:

1. `src/game.js`: `tickVolatile` обрабатывается раньше `tickEnemyLocomotion`; активный запал прерывает обработку перед обновлением подземного движения.
2. `src/systems/enemy-locomotion.js`: фаза `burrow/travel` делает врага неуязвимым.
3. `src/living-combat.js`: самоподрыв вызывает обычное повреждение владельца, которое `hurtEnemy` отклоняет из-за неуязвимости. Флаг `detonated` устанавливается, но повторные вызовы его не проверяют.
4. На следующих кадрах тот же живой враг снова создаёт взрыв. Аддитивные слои `volatileBlast` из `src/systems/soul-fx-view.js` накладываются, создавая белый круг с оранжевым краем.

`index.html` сравнивает текущие игровые рендереры подготовки, одиночного самоподрыва, ракеты и последовательности повторных самоподрывов. Проверено в Codex iab, без звука. Это изолированная визуальная диагностика, не запись пользовательского забега. Белый огненный диск воспроизведён; обрезанный край первого пользовательского кадра отдельно не воспроизводился.

## Исправление по следующему запросу пользователя

При начале запала снимается состояние движения, включая подземную неуязвимость. Та же очистка восстанавливает ранее застрявших врагов. Уже установленный `detonated` запрещает новый взрыв и повторный урон игроку; владелец проходит обычную обработку смерти.

Из `volatileCharge` удалены пламя, свечение и искры вокруг корпуса. Предупреждающая область на земле сохранена.

`fixed-reproduction.json`: тот же шестисекундный прогон теперь даёт один взрыв и 0 HP для обоих врагов. Прошли 32 проверки в `living-combat.test.mjs`, `enemy-locomotion.test.mjs`, `soul-fx.test.mjs`, включая естественное подземное приближение и восстановление уже взорвавшегося врага. `git diff --check` чист.

`fixed.html` и `fixed.png`: проверка в Codex iab на штатной симуляции, игровой модели Землекопа и текущем рендерере эффектов; подготовка без пламени, один взрыв, отсутствие частиц после его завершения. Используется подготовленное ровное поле, это не пользовательский забег. Скриншот `comparison.png` выше сохраняет исходное состояние до исправления.
