# Веб-сборка BIOSO для itch.io

`npm run build` выпускает оптимизированную основную игру в `dist/`. Все режимы,
модели, изображения и музыка включены в комплект. Размер больше 100 МБ разрешён.
При превышении 500 000 000 байт команда завершается ошибкой. Считается сумма размеров всех файлов,
включая манифест и общие текстуры; ZIP и серверное сжатие не используются в замере.

## Сборка и проверка

- `npm ci` — установить зафиксированные зависимости.
- `npm run build` — обработать оригиналы и собрать игру.
- `npm run verify:assets` — проверить манифест, исходные хеши, декодирование
  изображений и моделей, точность геометрии и карт материалов, сохранность аудио.
- `npm run preview` — открыть основную production-сборку.
- `npm run build -- --with-acceptance` — дополнительно создать проверочную сборку
  в `temp/optimized-acceptance` с теми же ресурсами и существующими review-маршрутами.

Отчёты: `temp/build-size-report.json`, `temp/asset-verification.json`.
Команда `npm run dev` продолжает использовать исходные ресурсы. Зафиксированные
игровые версии в `bioso-play/releases` не обновляются автоматически.

## Обработка ресурсов

Оригиналы остаются в `public/`. Во время сборки создаётся отдельный временный
каталог; после завершения удаляется только каталог текущего вызова.

- WebP для изображений: качество 85, способности до 384 пикселей, остальные
  отдельные иконки до 512, иллюстрации до 1024, фоны до 1536 по длинной стороне.
- Логотип и атласы интерфейса сохраняют размер и используют сжатие без потерь.
  Десктопный фон меню `menu-art-desktop-v1.png` также сохраняет исходное разрешение
  и все пиксели: уменьшение и сжатие с потерями для него отключены.
  Атласы окружения и фрагменты периметра сохраняют размер и расположение пикселей,
  используют качество 90 и сжатие альфа-канала без потерь.
- Цветовые текстуры GLB используют WebP 85 без уменьшения разрешения. Карты
  нормалей, metallic/roughness, occlusion и неизвестные слоты сжимаются без потерь;
  исходное изображение сохраняется, если WebP оказался больше.
- Одинаковые текстуры хранятся один раз в `assets/model-textures/`. GLB ссылаются
  на них относительными URI. При переносе игры нужно копировать весь `dist/`.
- Meshopt меняет порядок хранения геометрии и сжимает её. Квантизация, упрощение
  и удаление треугольников не применяются. Проверка сравнивает точные атрибуты
  треугольников и направление обхода, структуру сцены, трансформации и анимации.
- Звук, музыка, лицензии и прочие файлы копируются без изменений.

`asset-manifest.json` содержит соответствие исходного URL итоговому, хеши,
размеры и список общих текстур. Build-плагин использует его для строк и шаблонов
JS, HTML и CSS, включая вложенные CSS-импорты. Исходники игры не переписываются.
Имена вида `icon.png.webp` исключают конфликт между одноимёнными PNG и JPG.
