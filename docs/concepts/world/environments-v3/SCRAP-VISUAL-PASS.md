# Свалка: визуальный проход v7 — 2026-09-10

Запрос пользователя: сначала приблизить **игровую сцену** к референсу по свету, плотности, мелким камням, кустам и корням; полный прогон тестов отложить.

## Что изменено

- Только свалка Выживания: каменные насыпи вместо повторяющихся керамических рядов, более близкая композиция турбины и боковых масс, вторичная разрушенная турбина вместо нижнего блочного сооружения.
- Мелкий гравий на тропе, крупнее обломки у насыпей, фактурные кусты из существующего атласа на пространственных листовых плоскостях, геометрические корни с разветвлениями и сужающимися концами. Не новые цельные billboard-декорации.
- Более низкий тёплый ключевой свет с прохладным заполнением. Статическая видимость солнца на земле запекается из геометрии в GPU-текстуру один раз при загрузке клетки; после этого читается существующим ground shader. Не включены покадровые Three.js shadow maps. Крупные пятна рассеянной тени дополняют детальные силуэты.
- Для свалки переиспользован каменный материал вместо прежней земляной текстуры на валунах. Небольшая примесь минерала в землю и более заметная микронормаль. Нет новых загружаемых текстур или GLB.
- Миссии и другие окружения не получают новый слой и параметры света. Общая инфраструктура рендера расширена для дополнительной запечённой текстуры; временные render target освобождаются при выгрузке.

## Итерации по видимым недостаткам

v1 — слишком равномерные свет и земля, геометрические листья плоские.
v2/v3 — реальный силуэт теней и фактурные листья; земля стала слишком белой и пятнистой, кусты слишком тёмными.
v4 — более мелкая россыпь, светлее листья, убраны заметные швы текстуры.
v5 — корни через всю тропу выглядели как кабели; заменены на короткие, разветвлённые и сужающиеся корни в v6.
v6 — повторяющиеся керамические ряды оставались главным композиционным дефектом; в v7 изменён способ построения масс: отдельные объёмные камни вместо этих рядов.

## Доказательства

`docs/proof/forest-living-20260909/scrap-reference-vs-game-v7.png`: слева исходный референс, справа настоящий игровой кадр.

Текущие снимки: `scrap-visual-v7-390.png`, `scrap-visual-v7-360.png`, `scrap-visual-v7-wide.png` с JSON рядом. Широкий кадр снят с acceptance-сборки на 4185; мобильные — с того же source в dev на 4186. Нет зарегистрированных shader/asset ошибок на просмотренных кадрах. Полный тестовый suite, stress, финальная проходимость изменённой композиции, GPU residency и физический телефон **не проверялись** в этом проходе по запросу пользователя. Сборки production и acceptance завершились; сохранились прежние предупреждения о UI/art путях и размере JS chunk.

Это **не визуальная приёмка 8/10**: силуэты крупных объектов, материалы турбин, менее равномерный рисунок насыпи и выразительность света пока заметно уступают референсу. Снимок Blender не используется как доказательство качества игры. Следующий проход должен продолжать именно сравнение сцены, не тиражировать текущий вид по всем биомам.
