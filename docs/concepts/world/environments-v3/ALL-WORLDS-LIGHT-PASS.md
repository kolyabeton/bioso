# All environments: geometry shadows and understorey — 2026-09-10

Visual iteration, not final reference acceptance. User prioritised appearance
before stress/performance acceptance. No runtime assets were added in this pass.

## Implemented

- Static light-space depth rendered once for each loaded cell (1024²), sampled
  by its existing Standard materials. Ground, walls, foliage, roots and raised
  terrain can now receive geometry-based sunlight occlusion. No per-frame
  shadow-map render and no new real-time light.
- Applies to all five Survival environments and all five mission environments.
  Authored Survival Forest ground retains its existing offline visibility map;
  its models receive the new depth shadows. Mission Forest uses the new bake.
- Warm directional sunlight with cool hemisphere fill. Small moving hero
  contact shadow outside the Forest ambient system.
- Family-specific understorey: narrow garden evergreens, broad scrub in scrap,
  fern beds in city, denser roots/ferns in nursery. Reuses foliage/material atlas.
- Survival landmarks are closer to the central vista; city gains the existing
  ceramic arch mesh. Existing model bounds remain authoritative. Low dressing
  does not add colliders. Gameplay API and saves are unchanged.
- Diagnostics: `environmentShadowMode`, `staticShadowCells`. Existing `shadows`
  remains the legacy real-time-shadow-map flag, not static visibility status.

## Evidence and limits

Current built-game screenshots and JSON sidecars:
`docs/proof/forest-living-20260909/world-light-final-*-390.*`.
Contact sheets are generated by `assemble-world-light.mjs` in that directory.
Screenshots are actual game renders; reference art is never rendered as scenery.

Both isolated production and acceptance builds succeeded. Exact output sizes
are in `docs/proof/forest-living-20260909/build.json`; unrelated assets also
changed in the shared workspace, so these are not the byte delta of this pass.

Not accepted as 8/10 reference parity: large meshes still have simple shapes,
plant clumps remain too uniform, and surface detail is weaker than the targets.
This depth bake is static: wind does not update silhouettes, adjacent-cell
casters are not included in a cell's bake, and dynamic actors do not cast full
geometry shadows. Authored Forest keeps its prior key/bake direction; transitions
into other cells need a dedicated lighting-continuity pass.

Depth targets are disposed with their streamed cell. A 1024² RGBA target plus
depth attachment costs approximately 8 MiB per resident cell. GPU-residency,
50-transition/reset and 30-minute stress acceptance were intentionally deferred.
No phone-temperature or original triangle/p95-budget claim is made. Current
390×844 visual samples are recorded in `world-light-visual-summary.json`;
several non-Forest scenes exceed the earlier 410,000-triangle target.
