# Material sources

Generated with the built-in imagegen tool, not the CLI. Style reference: `docs/references/biomecha-style-master.png`. Four source images stay in this directory; runtime uses one packed WebP atlas built by `scripts/art/build-environment-material-atlas.mjs`. These are ground albedos, not environment cards. Lighting and geometry are rendered in-engine.

Use case: photorealistic-natural. Asset type: seamless tileable game ground BASE COLOR / ALBEDO texture, square 2048x2048. This image will be mapped on a real 3D terrain and lit in-engine. Avoid illustration, stylization, LEGO, toy forms, oversaturation and repeated neat pattern. About 4 by 4 metres of ground, varied natural scale. Neutral pale grey limestone, not yellow or gold.
