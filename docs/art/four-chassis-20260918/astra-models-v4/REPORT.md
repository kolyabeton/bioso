# Перенос выбранных исходников в 3D: v4

Исходные concepts-v3 выбраны пользователем как дизайн, см. [решение](../APPROVED_DESIGN.md). Их точные PNG уже используются в игровых иконках. Этот пакет — **отдельный приблизительный перенос объёмов в геометрию на согласование**, не замена выбранного дизайна и не побитовое воспроизведение изображения. В игру GLB пока не подключены.

## Форма

- Демонтажник: низкая куполообразная оболочка из крупных выпуклых секторов, круглая верхняя камера, круглые крепления и нижние венты.
- Регулировщик: отдельные овальные щёки, выступающий узкий центральный контур, три ступенчатых ребра.
- Дозорный: объёмный пятигранный панцирь, крупные сектора вокруг центрального люка, боковые панели и три механизма.
- Сборщик: два плавных плеча, прямоугольный механический отсек, передняя керамическая перемычка и пять задних кассет.

Главные поверхности параметрические; основная керамика не состоит из прямоугольных box-примитивов или навязанной мелкоплиточной сетки. Керамические окончания закрывают промежутки на вершинах плеч/щёк. Шаг сеток уменьшен для скрытых и мелких поверхностей; основные силуэты сохранены.

## Выполненные проверки

- Генерация и повторное чтение четырёх `body-<key>-astra4-v3.glb` через NodeIO.
- У каждого корпуса отдельный однозначный `<key>-steel` hull. После сварки совпадающих координат: 2760 рёбер, 0 открытых/неманифолдных рёбер и 0 вырожденных треугольников. Атрибуты конечны.
- Все встроенные PBR-изображения по SHA-256 совпадают с каноническими картами `leg-worker.glb`. Используются `CHASSIS_MATERIALS` и `equipmentSurfaceUV`; новые текстуры не создавались. Экспорт three.js → glTF сохраняет UV напрямую; Blender используется для просмотра, не для повторного экспорта.
- Реальный `structuralFrame.fit` нашёл все 3/2/2/3 поверхности крепления рук и 4/3/5/3 ног.
- Реальный `mountOrgan` установил все 3/4/3/5 органов, включая пятый орган Сборщика. Точки и нормали: `mount-checks.json`.
- Сборки используют настоящие текущие GLB рук, ног и органов, действующие `equipmentLayout`, `fittedModel`, `legMountOptions`, `createCreatureFrame` и `mountOrgan`.
- Версионные IDs заканчиваются `-v3` для существующего исключения дополнительной головы. `proposed-profiles.json` содержит предложения, игровые профили не заменены.

## Превью и границы проверки

Рендеры игровых ракурсов четырёх отдельных GLB и четырёх полных сборок получены через Blender. [Сравнение](original-concept-vs-v4.jpg) показывает выбранные исходные PNG сверху и фактическую геометрию снизу; [сборки](assembly-review.jpg) — настоящее установленное оборудование. Не заявляется точное совпадение всех деталей и материалов генеративного рисунка с текущим игровым атласом.

Проверки offline. Браузерная регистрация/загрузка новых IDs, движение, отдача и динамические пересечения не проверены. Высокие отдельные плечи вокруг raycast hull особенно требуют проверки посадки органов в игре после согласования. Никакого runtime PASS или окончательного отсутствия пересечений не заявляется. Src/public/manifest не изменены.

## Воспроизведение

Из корня проекта:

```sh
node scripts/asset-kit/four-chassis-astra-v4.mjs
node docs/art/four-chassis-20260918/astra-models-v4/audit.mjs
/opt/homebrew/bin/blender -b -t 6 --python docs/art/four-chassis-20260918/astra-models-v4/render.py -- --review-only
python3 docs/art/four-chassis-20260918/astra-models-v4/contact.py
```

Первичную геометрию и исходники подготовила Астра; родитель завершил закрытие крыши/перемычки/малых окончаний и уменьшение лишней геометрии. Старые версии сохранены.
