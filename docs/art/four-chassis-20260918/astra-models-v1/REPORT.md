# Четыре корпуса — предложения Астры v1

Статус: **на согласовании, в игру не подключены**. Самостоятельная новая геометрия по рабочим concepts-v3; не переименованные вражеские ядра. Генератор пишет только в эту папку.

## Результат

- Демонтажник: низкий широкий блок, раздельные створки и центральная камера ниже верхней керамической поверхности.
- Регулировщик: вертикальный блок, две боковые панели, узкое окно, три раздельных ступенчатых охлаждающих ребра.
- Дозорный: пятигранная стальная оболочка, перекрывающиеся панели, центральный люк и три встроенных неактивных механизма. Эффекты кругов отсутствуют.
- Сборщик: открытый сверху рабочий отсек, две направляющие и пять задних кассет.

Модели содержат только корпус. Руки, ноги, устанавливаемые органы и отдельная голова не встроены. Отдельные `*-assembled.glb` — технические демонстрационные сборки с настоящими текущими деталями.

## Переиспользование

- Канонический алгоритм группировки деталей по материалам и экспорт GLTFExporter/NodeIO из `scripts/asset-kit/chassis-v3.mjs`.
- `equipmentSurfaceUV` и окна керамики/стали/металла из `src/equipment-surface.js`.
- PBR-карты (base color, metallic/roughness, normal, occlusion) из `public/assets/kit/leg-worker.glb`, без перекраски и генеративных замен. SHA-256 всех четырёх встроенных изображений совпали с источником.
- Керамика, сталь, металл, стекло и свет из `CHASSIS_MATERIALS`. UV экспортируются напрямую three.js → glTF; Blender используется только для импорта и рендера, поэтому дополнительный V-flip НЕ нужен и НЕ применялся.
- В полных сборках — оригинальная геометрия настоящих `arm-*-icon-v1`, `arm-pistol-v1`, `arm-shield`, `leg-universal-icon-v2`, `leg-plated-icon-v2`, `organ-*-icon-v1`. Никаких нарисованных конечностей.
- Реальные `equipmentLayout`, `fittedModel`, `legMountOptions`, `mountOrgan`, `createCreatureFrame` и сопряжения текущего сборщика.

## Реально выполненные проверки

1. Экспорт GLB и повторное чтение NodeIO; импорт всех восьми GLB в Blender 5.2 для рендеров.
2. У каждого корпуса один однозначный raycast hull с именем `<key>-steel`; origin внутри замкнутой оболочки, `closedChassis: true` на корне. После сварки совпадающих координат все рёбра hull имеют по две грани; ноль открытых/неманифолдных рёбер и вырожденных треугольников. Все числовые атрибуты конечные.
3. Настоящий `structuralFrame.fit` вызван для каждой новой модели. Успешно найдены все поверхности 3/2/2/3 рук и 4/3/5/3 ног; реальные координаты и нормали сохранены в `mount-checks.json`.
4. Настоящий `mountOrgan` успешно установил 3/4/3/5 органов. Не ограничивали Сборщику пятый слот. Все результаты лучей сохранены в `mount-checks.json`.
5. Имена `body-*-astra-v3` соответствуют действующей проверке `endsWith('-v3')`, поэтому ветка автоматической головы не срабатывает. Структурный каркас при fit скрывает старые шею, подкладку и таз.
6. Полные сборки с реальными деталями отрендерены отдельно. Видны занятые крепления; часть дальних деталей закономерно перекрывается корпусом с игровой камеры.

## Ограничения

Это offline-проверка реальной геометрии и функций креплений. `loadModel` через браузер, игровой маршрут, движения/отдача и динамические пересечения не проверены; модели не зарегистрированы в manifest и BODY_MODELS. Не заявляем runtime PASS или окончательное отсутствие пересечений. В частности, посадку органов над высокими керамическими панелями следует проверить на игровых анимациях после согласования. Профили в `proposed-profiles.json` сохраняют текущую сетку слотов и меняют только предлагаемый modelId; это предложение, не применённые изменения.

## Файлы и воспроизведение

- `body-{demolition,regulator,sentinel,assembler}-astra-v3.glb` — четыре корпуса.
- `{key}-{front,back,underside,game-camera}.png` — 16 оригинальных рендеров экспортированных GLB.
- `{key}-assembly.png` и `{key}-assembled.glb` — четыре собранных превью и их геометрия.
- `models-review.jpg`, `assembly-review.jpg` — контактные листы с русскими названиями.
- `scripts/asset-kit/four-chassis-astra-v1.mjs` — исходник генератора (от корня проекта).
- `render.py`, `contact.py` — воспроизводимые офлайн-рендеры и контактные листы.

Из корня проекта: `node scripts/asset-kit/four-chassis-astra-v1.mjs`; затем `/opt/homebrew/bin/blender -b -t 6 --python docs/art/four-chassis-20260918/astra-models-v1/render.py`; затем `python3 docs/art/four-chassis-20260918/astra-models-v1/contact.py`.

Ни один файл в src, текущие public GLB, текстуры, manifest или тесты этим подэтапом не изменялись.
