# Утверждённое окно сюжетного диалога

Визуальный референс: `dialog-window-approved-v1.png`.

- Тёплая белая состаренная керамика.
- Толстая округлая оболочка с двойным внутренним бортиком.
- Тёмная типографика без отдельной шапки.
- Небольшой вертикальный мятный индикатор слева.
- Кнопка закрытия не меньше 44×44 CSS px.
- Окно остаётся внутри портретной ширины игровой сцены.

Реализация: `src/ui/story-radio.css`.
