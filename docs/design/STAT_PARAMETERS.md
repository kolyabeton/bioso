# BIOSO — таблица параметров и аудит текстов

Срез исходников: 20 сентября 2026. Уточнение принято: `interval` и `rate` — разные уровни одного параметра; `reloadDuration` и бонусы перезарядки — тоже. Документ для согласования единого словаря. Текущий игровой вывод и баланс этим документом не изменены. Предложения ниже не заменяют действующий `docs/UI_ITEM_CONTRACT.md` до внедрения.

## Правило переиспользования

Сначала ищем характеристику в этом реестре и в UI_ITEM_CONTRACT. Если смысл, объект и единица совпадают — используем существующий параметр и общий вывод. Разные внутренние источники одного бонуса не создают новые строки UI. Совпадение слова само по себе не означает совпадение механики: урон попадания, бонус урона и доля урона вторичного эффекта различаются.

Это реестр игровых характеристик, существующих строк и описаний, а не перечень всех технических полей сохранения. Счётчики таймеров, координаты, идентификаторы и флаги реализации не становятся статами. Текстовые «Эффект», «Особенность», «Синергия» — контейнеры описания, не новые числовые параметры.

## Правила чисел и расчётов

- Абсолютная величина: `2 с`, `12 м`, `1,5 м/с`; бонус: `+20%`; сокращение времени: `−20%`; множитель: `×1,5`.
- Шанс 5% → 10% означает прибавку +5% к значению шанса (итог 10%).
- Доля урона 50% означает половину исходного попадания. «+50% урона» означает множитель 1,5.
- Для бонуса скорости r сокращение времени равно r/(1+r). Прямое сокращение времени уже является нужным процентом. Разные источники не заменять одной внутренней формулой.
- Показ индивидуального бонуса описывает его отдельный эффект. Итог сборки получать из механики с текущими ограничениями и совместимостью; округлённые проценты отдельных источников не складывать.
- Запятая в русских дробях; формат `N из M`; единицы одинаковы между экранами. Точность — по действующему контракту, изменения точности согласовывать вместе с выводом.
- Условия, длительность и объект обязательны для условных бонусов. Не превращать имя способности в новый постоянный стат.
