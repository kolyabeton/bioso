# Контракт параметров и вывода предметов BIOSO

Обязателен для новых и существующих предметов, инвентаря, креплений, игрового HUD, наград, добычи, инспектора, атласа и сравнения сборки. Зафиксирован по текущему общему выводу, за исключением несогласованной строки DPS у щита: она удалена.

## Изменения только по запросу пользователя

- Списки ниже закрытые: новый вычисляемый показатель, название, порядок, единица, точность, условие видимости или исключение для одного предмета требуют явного запроса пользователя.
- Описание механики, балансировочный термин и проверочный расчёт не разрешают новый UI-параметр. «5 ДПС» в задаче означает ориентир баланса, а не строку в карточке.
- DPS / ДПС / урон в секунду отдельной строкой предмета не выводить. В Душе DPS установленного оружия сборки показывать строкой «Общий урон в сек» через `loadoutDps`, при наличии активной руки; это не параметр предмета и не строка инспектора.
- Не использовать скриншот, проверочный маршрут или текущую ошибочную реализацию как новое одобрение. Не возвращать отдельный экран «Деталь» и связанные экраны свойств/снятия.
- После согласованного изменения обновлять этот контракт, общий источник данных и профильные проверки одновременно. Ожидания проверок не перезаписывать автоматически из фактического вывода.

## Единственные источники вывода

- `src/ui/item-inspector-data.js`: `itemInspectorData` для экземпляра; `catalogInspectorData` для атласа.
- `src/ui/adapters.js`: `partPropertyRows` для особых свойств, `describePart` для текстового вывода добычи, `cardData` для компактной карточки, `comparisonRows` для сравнения.
- `src/ui/item-tooltip.js`: действующий общий `item-inspector`; отображает переданные данные и ничего не рассчитывает/не дописывает.
- Числа получать из игровой механики (`assembly.js` и профильных систем), не дублировать формулы в HTML, обработчике отдельного предмета или проверочной странице.
- Атлас описывает базовый экземпляр выбранного ранга с бонусами текущей сборки, без случайного модификатора, усилений, действий и изменения состояния игры.
- Описание способности Мойщика в атласе объясняет прибавку за запас биомассы без подстановки текущего количества биомассы и текущего бонуса.
- В описании предмета в атласе не показывать фразы о выпадении в выживании и победе над боссом для разблокировки.

## Общая композиция

1. Заголовок: общая иконка предмета, название, тип («Рука», «Нога», «Корпус», «Орган»), римский ранг; модификатор, редкость и набор при наличии. Иконка одна и та же на всех поверхностях, через `partArt`.
2. Для установленного улучшаемого предмета — выбранный параметр улучшения и фактический предпросмотр «сейчас → станет», затем «Усиления N из M». У корпуса и Ремкомплекта — по 10 улучшений. Не показывать расчёт вместо реального результата и не менять игру ради предпросмотра.
3. Таблица параметров по категории, в порядке ниже; «Вес» всегда последним. Нет пустых строк, `undefined`, `NaN`, дублирующих строк и скрытых дополнительных характеристик.
4. Общие свойства редкости/набора и способность корпуса идут в описании после таблицы. Числа основных параметров там повторно не перечислять. Строки «Состояние бонуса», «Активно/Неактивно» и отдельный блок «Бонус корпуса» для корпуса запрещены.
5. Нижние действия определяются существующим контекстом: биомасса, «Улучшить · стоимость» / «Улучшить бесплатно», установка из инвентаря, настройки при наличии желудка, выброс, переработка. «Переработать» всегда последняя кнопка карточки, ниже «Выбросить». Никаких новых действий из-за нового предмета. Неустановленные предметы не улучшаются; подсказку «Улучшение доступно после установки» не показывать. Атлас не имеет действий.
6. Длинные свойства — строка на полную ширину: сейчас это `wide: true`, если значение длиннее 30 символов; эффекты органов всегда на полную ширину. Геометрия, прокрутка и кнопки — по `docs/UI_MOBILE_CONTRACT.md`.

## Основные строки: порядок, единицы, условия

| Категория | Строки в обязательном порядке |
| --- | --- |
| Рука | «Урон» → «Интервал атак» → «Дальность» → «Крит» (кроме `drone`) → «Магазин» либо «Заряды» и «Время перезарядки» (только при наличии магазина) → особые свойства из списка ниже → «Вес». Щит: «Урон ауры» → его особые свойства → «Вес» |
| Корпус | «Здоровье корпуса» → «Броня детали» (если собственная броня ненулевая) → «Вместимость» → «Крепления» → «Бонус скорости» (если есть) → отдельная строка базового бонуса (если есть) → «Вес» |
| Нога | «Скорость движения» → «Здоровье детали» (если > 0) → «Броня детали» (если собственная броня ненулевая) → «Регенерация» (при `regen`) → особые свойства из списка ниже → «Вес» |
| Орган | «Здоровье детали» (только `reverseStomach`, как у ноги) → «Броня детали» (если собственная броня ненулевая) → «Эффект» → дополнительные «Свойство» / «Бонус корпуса» только по закреплённым условиям ниже → «Вес» |

- «Урон»: текущее значение `weaponStats.damage`, без единицы, до 1 десятичного знака; не пересчитывать в DPS.
- «Интервал атак»: фактическое время между атаками `weaponStats.interval` в секундах. Процентный бонус «Скорость атаки» выводится только на поверхностях бонусов сборки. «Дальность»: `weaponStats.range` в метрах, до 1 десятичного знака. У атак рук радиус корпуса учитывается один раз: у ближнего оружия он уже включён в `weaponStats.range` через `heroMeleeAttackRange`, у дальнего добавляется в боевых проверках от центра.
- «Крит»: `шанс% · ×множитель`; шанс — целые проценты, множитель — до 2 десятичных знаков. `drone` строку крита не имеет.
- «Заряды» — для режимов `sector`, `area`, `contact`; иначе «Магазин». Формат `текущие из максимальных`, а не `текущие/максимальные`. «Перезарядка»: фактический `reloadDuration` в секундах.
- «Здоровье корпуса»: целое число + ` HP`; каждый ранг выше I добавляет 0,5 прежнего деления, то есть 12,5 HP до округления. «Здоровье детали»: `+целое число HP`. Общий максимум сборки округляется один раз после суммирования всех источников; отдельная строка предмета округляется сама и потому сумма показанных строк может отличаться от прироста сборки на 1 HP. «Броня детали»: число + ` пласт.`. Броня сохраняет прежние целые и половинные пластины и блокирует прежнее число попаданий.
- Собственная броня учитывает ранг, усиления и модификатор `armored`, но не броневой аффикс: аффикс уже указан в общем описании и не дублируется строкой. Броня всей сборки не подставляется вместо брони детали.
- «Вместимость»: целое значение; для установленного корпуса учитываются бонусы сборки, для запасного — `capacity(part)`. «Крепления»: `Рук: N · ног: N · органов: N`, число органов учитывает существующие расширения установленного корпуса. Корпус получает по одному естественному слоту органа на III и V рангах; из редкостей только легендарная добавляет ещё один слот, с сохранением индивидуального предела корпуса.
- У Каменщика обычной редкости 3 слота органов на I ранге, 4 на III и 5 на V; его предел — 5. Бонус корпуса требует четыре установленных органа.
- На I ранге у Садовника 3 слота органов, у Механика 2, у Сборщика 3. У Высотника 3 крепления ног; третье находится сзади корпуса.
- «Скорость движения»: число + ` м/с`; «Регенерация» ноги в инспекторе и предпросмотре улучшения: число + `%`, без подписи скорости, чтобы значение помещалось.
- Базовая скорость сборки с установленными ногами — сумма скоростей ног, делённая на число креплений ног корпуса, плюс бонус корпуса: Садовник +3 м/с; Мойщик и Электрик +2 м/с; Механик, Пасечник, Высотник и Регулировщик +1 м/с. Без установленных ног скорость равна нулю. Бонус корпуса применяется до процентных бонусов. Общий предел итоговой скорости движения — 18 м/с.
- «Бонус скорости» всегда отдельной строкой `+N м/с`. В следующей строке: Садовник — «Уклонение» `+20%`; Электрик — «Восстановление Кожуха» `+40%`; Высотник — «Критический урон» `+25%`; Каменщик — «Получаемый опыт» `+10%`; Мойщик — «Длительность кислотных луж» `+50%`; Лесник — «Восстановление здоровья» `1%/с`; Регулировщик — «Урон по замороженным врагам» `+30%`; Механик — «Время перезарядки оружия» `−10% за каждые +10% скорости атаки`. Для Механика считаются полные ступени бонуса скорости конкретного оружия; сокращение ограничено 80%. Пасечник получает только строку скорости; у Дозорного, Сборщика и Демонтажника дополнительных строк нет. Эти значения одинаковы для установленного и запасного корпуса и атласа, не повторяются в описании способности.
- «Вес»: фактический `weight(part)`, целое округлённое значение, без единицы; учитывать существующие правила ранга и модификаторов, не подменять базовым весом.
- Все дробные числа — с запятой, без ненужных конечных нулей; по умолчанию до 2 десятичных знаков, кроме явно заданной выше точности. Не менять единицы между рангами.

## Закрытый список особых строк рук

Синергии Рассеивателей и Маркеров учитывают каждый установленный экземпляр, включая первый. Каждый Рассеиватель даёт −10% времени перезарядки и −10% разброса всем Рассеивателям: три дают −30%, четыре — −40%. Каждый Маркер даёт +5% к шансу крита и +0,2 к множителю крита: четыре дают +20% и +0,8. Душа показывает итог из `weaponFamilyBonus`; запасные предметы не учитываются.

Названия в ячейках перечислены в порядке вывода. Значения берутся из текущей механики, существующие короткие пояснения остаются в этих строках, не превращаются в новые параметры.

| Ключ | Особые строки |
| --- | --- |
| `drone` | «Призыв», «Радиус удара» |
| `harpoon` | «Особенность»: «урон по элите и боссам +25%»; встроенного пробития и притягивания обычных врагов нет |
| `claws` | «Тип атаки» |
| `hammer` | «Тип атаки», «Особенность» |
| `shieldArm` | «Защита от снарядов», «Радиус ауры», «Замедление» |
| `drill` | «Особенность» |
| `whip` | «Тип атаки»: широкая дуга; каждое попадание сначала слегка отталкивает врага на 1 м, затем каждый третий основной удар стягивает обычных врагов до 5 м, элит до 1 м за 0,18 с; боссы неподвижны. Точка сбора — конец удара по текущей игровой дальности сучкореза, а не рядом с героем. В UI — качественное описание без новых числовых строк. Цикл отдельный для руки, перезарядка его не сбрасывает, эхо не продвигает. |
| `fangs` | «Эффект» |
| `seed` | Нет |

| `shotgun` | «Залп», «Разброс», «Синергия» |
| `needle` | «Пробитие» |
| `rocket` | «Усиления», «Залп», «Радиус взрыва», «Особенность» |
| `arc` | «Цели» |
| `acid` | «Длительность лужи»: текущие 3 с с учётом бонуса корпуса и «Долгого тления» |

Радиусы — в метрах; длительность — в секундах; пробитие, цели, число снарядов/дронов — количеством с существующей подписью. «Эффект» Захвата показывает восстановление 5/6/7/8/9% максимального HP при каждой атаке на рангах I–V. Каждый установленный Захват использует собственный ранг; запасная деталь и атлас показывают его же процент. Дробная часть лечения накапливается до целого HP, при полном здоровье не сохраняется. Синергии, разброс и особые правила — существующее описание из `partPropertyRows`, без дублирования общего урона, дальности, критов, магазина и перезарядки.

Щит не атакует. На I ранге его аура наносит 10 урона/с в радиусе 5 м и замедляет на 10%. Ранг I–V повышает базовый урон ауры до 10/10,8/11,6/12,4/13,2 за секунду; улучшения `damage` усиливают только ауру. Урон и замедление нескольких включённых щитов складываются; вход в их общую зону считается одним наложением холода. Огонь усиливает периодический урон, «Долгое тление» оставляет остаточный урон после выхода, Холод усиливает замедление. Защита — `50% спереди · сектор 120°`, несколько щитов складываются до 80%. В Душе защита отображается отдельной строкой со значением `50%` либо фактическим сложением.

## Органы: содержимое эффекта

Для каждого органа один первый «Эффект» с фактическим текущим значением; не добавлять отдельные числовые строки по собственному усмотрению.

| Ключ | Содержимое «Эффекта» |
| --- | --- |
| `reverseStomach` | Существующее правило автопереработки/отсутствия лечения. Здоровье — отдельной строкой «Здоровье детали» в формате `+число HP`, без повтора в эффекте |
| `broodNode` | Бонус урона роя в %, правило двух сильнейших узлов |
| `mirrorGland` | Бонус изученных способностей в %, ограничения и сложение |
| `reflexNerve` | Шанс уклонения в % |
| `returnNerve` | Возврат снарядов и текущий процент урона, без восстановления боезапаса |
| `slime` | Каждое попадание оружием замедляет цель на 10% на 5 с и наносит за базовые 5 с 10–50% урона самого попадания на рангах I–V. «Вечная мерзлота» продлевает замедление, «Долгое тление» увеличивает время периодического урона при прежнем уроне в секунду; текущие длительности видны в эффекте. Каждое из 10 улучшений добавляет 1% к урону. Попадание считается одним наложением холода для «Кристаллизации». Несколько установленных Охладителей складывают урон и замедление (замедление ограничено 40%). При смерти поражённый враг взрывается: урон сильнейшего ещё действующего попадания Охладителя, радиус 2,5 м. Старой лужи после смерти нет. |
| `parasite` | Число личинок, интервал в с, поиск в м, урон одной личинки и влияние темпа роя |
| `commonNerve` | Рассеиватель, Лебёдка, Инъектор и Доставщик; правило общего залпа и текущий бонус в формате «+N% урона» (множитель 150% показывается как +50%); работает только один Синхронизатор — самый сильный |
| `reverseHeart` | Условие импульса, радиус в м, % от сильнейшей руки, перезарядка в с |
| `regen` | Непрерывное восстановление максимального здоровья в %/с; попадания не прерывают восстановление |
| `shield` | Число полных блоков и текущая задержка восстановления в с |
| `armor` | Запас брони, восстановление в %/с и отсутствие сброса от попаданий. Два улучшения усиливают только ремонт на +0,3%/с каждое; предпросмотр «Ремонт брони» показывает общий темп сборки в %/с. Улучшения доступны и при пределе запаса брони |
| `repairGland` | Бонус способности корпуса в %, правило двух сильнейших Ремкомплектов; без пересказа всех способностей корпусов |
| `stabilizer` | Сокращение времени перезарядки оружия в %: 15% × сила органа. Складывается с сокращением Рассеивателей; общее сокращение ограничено 80%. Скорость снарядов не меняет. |
| `accelerator` | Бонус скорости атак в % |
| `digestion` | % базовой биомассы и множитель переработки |
| `revivalCore` | Срабатывает из инвентаря; бонусы также действуют из инвентаря, установка не обязательна; условие воскрешения, 25 HP, защита 2 с и одноразовость |

У `digestion` после эффекта только «Свойство»: несколько желудков не усиливают эффект. «Бонус корпуса» отдельной строкой органа допустим лишь при фактическом усилении эффективности >1 для `reflexNerve`, `returnNerve`, `slime`, `parasite`, `commonNerve`, `reverseHeart`, `regen`, `shield`, `armor`, `stabilizer`, `accelerator`. У остальных органов эту строку не добавлять.

## Другие поверхности предмета

- Душа: описание бонуса корпуса показывает итоговые проценты с учётом двух сильнейших установленных Ремкомплектов, из системы способностей корпуса. Условия, счётчики и неусиливаемые пределы сохраняются. Отдельную подпись «Усиление Ремкомплектами +N%» не выводить. Базовое описание запасного корпуса остаётся без усиления.
- Активный бонус корпуса в Душе использует композицию карточки комплекта: шапка с иконкой корпуса, названием и подписью «Бонус корпуса», затем отделённая строка состояния и описание на полную ширину. У комплектов используются собственные простые иконки, а не иконка корпуса или общий запасной символ.

- Компактная карточка: иконка и название, римский ранг/редкость/набор по существующему контексту, вес. Числовую таблицу инспектора и DPS не переносить в карточку/HUD/награду.
- Текст добычи формируется через `describePart`, а не новым независимым списком. Общие параметры и особые строки не повторять одновременно в таблице и описании одной поверхности.
- Сравнение сборки: «Здоровье» → «Броня» → «Движение» → «Вес»; затем условные «Защита спереди», «Уклонение», «Щит», «Регенерация», «Восстановление корней», «Ремонт брони». При замене руки — «Урон оружия» → «Интервал атак» → «Дальность». Если сравнивается щит, добавить «Урон ауры» и показывать для него прочерки в строках атаки. При сравнении двух щитов строки атаки скрывать. Условия и значения — из общего `comparisonRows`; экран добычи показывает только изменившиеся строки. Общий DPS сюда не добавлять.
- Предпросмотр улучшения — только существующий выбранный ключ `upgradeOptions` / название `STAT_LABELS`, с существующими исключениями для единиц ног и эффекта органов; не добавлять новый улучшаемый параметр ради вывода.

## Защита от повторения

Свойства редкости остаются в общем описании предмета после таблицы. Новые бонусы рук и деталей, включая «Выжидание» (+25% урона этой руки после 3 с без движения, сброс при перемещении), выводятся отдельными строками через общий `affixDescriptions`; дополнительные числовые строки таблицы, DPS и отдельные всплывающие панели не добавляются. Старые сохранённые `affixes` и одиночный `affix` отображаются тем же способом.

`tests/item-presentation-contract.test.mjs` проверяет закрытые списки особых свойств, точный порядок строк каждой категории на рангах I–V в инвентаре, сборке и атласе, формат основных единиц и отсутствие DPS. Изменение без обновления согласованного контракта должно приводить к падению проверки, а не к автоматическому обновлению ожиданий.

## Единая регенерация

Все источники регенерации восстанавливают процент максимального здоровья непрерывно, без ожидания и сброса от урона. Ремонтник: 1%/с на I ранге, +0,3%/с за ранг выше I и за улучшение regenRate. Ноги сохраняют существующий темп. Восстановление души: 1%/с за уровень. Живые ткани: 1%/с. Источники складываются; запрет лечения действует. Душа и сравнение показывают один общий темп регенерации.

## Общий компонент таблиц

`src/ui/stat-table.js`: предметы, Душа, сравнение сборки и числовой блок события используют общий компонент. Общий стиль берётся из предмета: Onest 12 px, 400, строка 16 px; подписи приглушённые, значения основного цвета, цифры табличные; отступ строки 6 px и разделители с 45% цвета обводки. В Душе сохраняются две колонки и их обводка, h2 — 13 px/500. Длинные значения переносятся; строки предмета с wide сохраняют вывод на полную ширину.

## Текстовые компоненты

`src/ui/typography.js` предоставляет text, description, caption. Текст и описание: Onest 12 px/20 px, 400; текст основного цвета, описание приглушённое. Подпись: Onest 11 px/16 px, 400, приглушённая. Комплекты, корпус, изученные способности, мутации и свойства предмета переиспользуют эти роли. Состояние комплекта сохраняется словами и цветом, без отдельного жирного начертания.

Те же текстовые роли применяются в обзоре мутаций, карточках предложенных навыков, подробностях дерева, синергиях и малых усилениях; заголовки мутаций и подробностей навыка используют общий стиль h2.

## Ремкомплект и Пасечник

Ремкомплекты увеличивают число постоянных дронов корпуса Пасечника: ранг корпуса × (1 + сумма усилений двух сильнейших установленных Ремкомплектов), с округлением вниз. Требуется включённый Опылитель. Дроны оружия, Колонии и набора прибавляются отдельно. Описание корпуса показывает полученное число; новые строки параметров не добавляются. Десять улучшений Ремкомплекта можно покупать заранее, даже пока условие способности корпуса не выполнено.

Описания Опылителя и связанных с роем деталей состоят максимум из двух коротких предложений. Суммарный актуальный урон всех установленных и включённых Опылителей прибавляется до общих множителей к базовому урону всех существ роя и башен Сборщика: постоянных и временных дронов, личинок Инкубатора и Улья, дронов-камикадзе Доставщика, электрических башен. Описания называют источник усиления и область действия, но не повторяют параметры, уже показанные отдельными строками инспектора.

## Описания усиленных корпусов

Душа и описание корпуса в сборке используют общий `chassisDescription`: показывают усиленные Ремкомплектами величины способности, сохраняя условия, счётчики, интервалы и действующие пределы. У Демонтажника показывается текущее снижение брони, у Регулировщика — длительность заморозки, у Дозорного — доля урона отражения, у Сборщика — число и здоровье башен при текущей грузоподъёмности и усиленная доля урона Сварочника. При невыполненных условиях описание сохраняет условную формулировку способности.

## Бонусы Реаниматора

Случайные бонусы Реаниматора действуют как в инвентаре, так и в слоте органа: скорость движения и атак, броня, радиус притяжения опыта. Каждый экземпляр учитывается один раз; после выброса, переработки или разрушения его бонусы исчезают. Снижение собственного веса действует в обоих положениях по общему правилу. Вывод свойств остаётся общим, без дополнительных строк.

Электрик: каждое убийство повышает урон оружия на 1% и обновляет таймер. Через 3 с игрового боя без убийств весь накопленный бонус сбрасывается. Счётчик убийств за забег не сбрасывается. Ремкомплекты усиливают процент, но не длительность.

Дроны Доставщика живут не более 5 с полёта: при истечении времени взрываются, в том числе без цели. Попадание и перехват снаряда вызывают взрыв раньше; отдельную строку времени жизни в UI не добавлять.
