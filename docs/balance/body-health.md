# Здоровье корпусов

Максимум HP зависит от экземпляра установленного корпуса:

- Странник, Ловчий, Химера, Гекатон: база 2 HP.
- Бастион, Корнеход: база 3 HP.
- Ранг I–V: дополнительно 0 / 1 / 2 / 3 / 4 HP.
- Редкость: обычная +0, необычная +1, редкая +2, реликтовая +3 HP.

Бонусы ранга и редкости складываются. Например, редкий Странник III даёт 6 HP. Правило для реликтовой редкости определено, но само по себе не добавляет корпуса в существующий реликтовый пул добычи.

Дополнительно учитываются существующие бонусы способностей, сохранённые улучшения здоровья и цена хирургических сделок. Улучшение вместимости не добавляет HP. При смене корпуса сохраняется количество ран, включая раны сверх меньшего максимума. Карточка показывает здоровье самого корпуса; HUD и сравнение сборок учитывают общий максимум.
