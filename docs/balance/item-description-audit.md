# Сверка свойств и игровой логики

Проверены каталог частей, свойства редкости, комплекты, расчёт характеристик, атаки, обработка попаданий, здоровье, переработка и подбор опыта. Проверка исходников и автоматической симуляции; это не ручное проигрывание каждого сочетания в браузере.

Исправлены расхождения:
- Радиус сбора — радиус притяжения кружочков опыта, не количество опыта и не дальность подбора деталей.
- Разведчик сохраняет ускорение перезарядки 1 секунду после остановки.
- Клыки считают успешные попадания, а не любые попытки атаки.
- Показанная перезарядка оружия учитывает комплект и случайное свойство детали, как реальный таймер.
- Показанное восстановление регенератора учитывает ускорение корневыми ногами.
- Подписи креплений установленного корпуса учитывают дополнительные слоты от событий.
- Зеркальная железа не получает в подсказке обещание усиления корпусом, которого нет в её реализации.

Подбор проверен через настоящий шаг игры: смерть врага создаёт XP, вне 7 м кружочек не движется, с двумя типами Разведчика он притягивается внутри 8,05 м и начисляет ровно исходный опыт. Деталь на 4 м не подбирается. Случайное свойство радиуса действует только при установке. Новый тест также проверяет показанные таймеры и слоты.

Другие проверки пакета покрывают свойства редкости, бонусы корпусов, Химеру/Гекатона/Ловчего, магазины, пробивание, лечение, щит, броню, новые органы, переработку и события.

Результат общего прогона на момент сверки: 339 из 341. Две ошибки вне изменённой логики свойств: тест визуальных снарядов ожидает 4 разновидности вместо 5; тест креплений обнаруживает пересечение рук hunter/claws 0 и 2. Полного зелёного прогона нет. Сборка успешна. Мобильное описание проверено в настоящем атласе.
