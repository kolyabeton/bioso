# Пассивные способности тел

Существующие особенности каждого корпуса сохраняются. Дополнительно действуют бонусы строения:

- Четыре крепления ног: скорость движения ×1,15. Скорость по-прежнему зависит от установленных ног и перегруза.
- Три или четыре крепления рук: +15 процентных пунктов скорости атак всех рук в общей сумме бонусов. Перезарядка магазина не ускоряется этим бонусом.
- От четырёх доступных креплений органов: эффективность органов ×1,30. Считаются слоты текущего тела с учётом ранга, редкости и сделок, а не заполненность. Бонус действует один раз.

Бонусы сочетаются. Смена тела меняет их без накопления. Уже выпущенные снаряды сохраняют усиление на момент атаки; будущие атаки используют новое тело.

| Орган | Эффект усиления корпуса |
| --- | --- |
| Возвратный нерв | Обратный урон 60% → 78% |
| Слизевой мешок | Замедление от попадания длится 3 → 3,9 с |
| Паразитарная матка | Урон личинки 40% → 52% исходного попадания |
| Общий нерв | Добавочный урон залпа +100% → +130%, итог ×2,3 |
| Обратное сердце | Урон импульса ×3 → ×3,9 |
| Внешний желудок / пищеварительный орган | Базовый выход биомассы ×1,3; возврат потраченных ресурсов остаётся 50% |
| Регенератор | Интервал восстановления /1,3 |
| Щитовой орган | Новый цикл восстановления /1,3; заряд остаётся один |
| Бронепластины | Заряд за ранящее попадание 1 → 1,3 |
| Стабилизатор | Бонус скорости снарядов ×1,3 |
| Ускоритель восстановления | Бонус скорости атак ×1,3 |

Целые деления HP, количество личинок, радиус поглощения, боезапас и ограничения вторичных атак сохраняются.
