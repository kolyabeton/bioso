# Дальний рывок

Новое испытание выживания, доступное с уровня 8: один старт на карте, финиш на дальней стороне. Миссии сохраняют прежний набор событий. Награда — один выбор детали II уровня из обычного пула испытания.

До старта строится полный маршрут с проверкой препятствий и зазором 2,4 м. Частичный результат поиска пути не принимается. При отсутствии проходимого маршрута испытание недоступно. Лимит одинаков для любой сборки: `ceil(длина маршрута / 6.4 + 3)` секунд. Он не подстраивается под текущую скорость игрока. Окно старта показывает длину, время, скорость сборки и предупреждение для заведомо медленной сборки.

После старта:

- Финиш становится приоритетом стрелки; карта показывает проверенный маршрут пунктиром.
- На четверти, половине и трёх четвертях пути появляются группы по три врага при приближении игрока. Обязательного числа убийств нет.
- Обычные волны и часы прогрессии выживания стоят на паузе; бой, движение врагов и таймер испытания продолжаются. Пауза игры останавливает и испытание.
- Автоподбор деталей временно отключён, чтобы случайная добыча не перегрузила быструю сборку. Детали остаются на земле; другие виды подбора работают как прежде. Уже имеющийся вес сохраняет своё влияние.
- Живое существо должно добраться в радиус 3 м от достижимого финиша до истечения лимита. Награда доступна только на финише и выдаётся один раз. Опоздание завершает испытание без награды.

## Проверка баланса — 8 сентября 2026

Команда `node scripts/race-balance.mjs` использует настоящий `game.step`, обычный урон, движение с коллизиями и стрельбой. Управление автоматическое по проверенному пути, без телепортаций. Быстрая сборка дополнительно стоит 5 секунд, моделируя задержку игрока. Тяжёлая не получает этой задержки. Обе используют одинаковые руки III уровня и органы щита/регенерации, пустой инвентарь.

Быстрая прошла 6/6, тяжёлая опоздала 6/6; обе пережили все прогоны. В боевых прогонах уничтожено 8–9 монстров. Контроль без врагов на seed 20317: быстрая 46,25 с, тяжёлая всё равно опаздывает (12,5 м до финиша). Это исходная настройка для испытания скорости, а не гарантия результата для всех сборок и навыков ручного управления.

Файлы `proof/race-20260908/balance.json` и `balance.log` содержат числа прогонов. Подготовленный браузерный маршрут `?review=race&build=fast` или `build=slow` доступен только в dev/acceptance-сборке, использует изолированный профиль и реальные кадры игры. Кнопка «Автопробег» задаёт обычный ввод движения; можно переключиться на ручное управление.

В браузере на seed 20317 быстрая сборка прошла маршрут за 48,9 из 59 с (9 убийств, 1 попадание по игроку), тяжёлая опоздала на том же лимите (24,3 м до финиша, 9 убийств). В собранной acceptance-версии проверена цепочка: старт → бой и финиш → выбор детали → подтверждение → завершённое событие. Проверены 360×640, 390×844 и 1280×720; в широком окне сцена 405 px, диалог 389 px. Кнопки действий не переносятся и имеют высоту минимум 44 px; описание прокручивается до награды.

46 целевых тестов испытаний/событий и 17 проверок навигации/боссов/указателя проходят. Производственная и acceptance-сборки проходят. Общие проверки HUD/локализации на момент прогона имеют посторонние ошибки: Node не загружает CSS из world-label и отсутствуют переводы нового текста достижений/финального босса; отдельная проверка текстов нового испытания проходит.
