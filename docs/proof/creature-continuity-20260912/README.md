## Границы проверки

Полный набор тестов проекта не объявляется зелёным. При первоначальном запуске обнаружены отдельные ошибки: отсутствующий `repairGland` в реестре моделей и устаревшее ожидание здоровья финального босса. Эти две проверки исключены из профильного прогона. Тест общего GLB-манифеста также предполагает наличие `images` у каждого GLB, что не выполняется для части текущих ресурсов. Node-прогон использует локальный CSS import hook из `temp/creature-continuity/register.mjs`, поскольку импорт игрового представления тянет CSS.

Команда профильной проверки:

```sh
node --import ./temp/creature-continuity/register.mjs --test --test-skip-pattern='every catalog item|phase budgets are applied' tests/equipment-mounts.test.mjs tests/equipment-v2.test.mjs tests/hud.test.mjs tests/enemy-assembly.test.mjs
```

Это правка геометрии сборки и соединений, а не новая генерация исходных художественных моделей.
