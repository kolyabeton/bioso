# Прозрачность предупреждений атак

8 сентября 2026. Общая непрозрачность 0.2 (80% прозрачности) в `src/attack-warning-style.js`: направления выстрелов и рывков, круги и секторы ударов, кислотные предупреждения, старые линии прицеливания стрелков. Кислотный шейдер сохраняет мягкую форму, ограничивая alpha значением 0.2. Сама кислота после попадания остаётся отдельным игровым эффектом.

Направленные зоны теперь плоские: прежний BoxGeometry накладывал несколько прозрачных граней и давал более плотный квадрат. Удалено изменение прозрачности общего материала в зависимости от последнего экземпляра атаки.

Проверены настоящие маршруты миссий garden/core/mother при 360×640, 390×844 и 1280×720: девять случаев без переполнения и ошибок загрузки. На широком экране портретная сцена 405 px. Скриншоты и данные — рядом в этом каталоге. Проверочный вход в финальную комнату с неуязвимым героем; кнопка Attack продвигает настоящую симуляцию до атаки и фиксирует позу.

Production-сборка проходит (`build.log`). Тесты предупреждений и механик миссионных боссов проходят (`tests.log`). Дополнительный прогон `enemy-tactics` выявил независимое несоответствие количества снарядов: 3 вместо 1 на строке 14; этот тест не использует изменённые модули отображения (`extended-tests.log`). Боевые правила не изменялись.
