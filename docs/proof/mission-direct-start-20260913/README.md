# Прямой запуск миссии

Выбор доступной миссии вызывает штатный старт игры. Промежуточный экран «Задание» удалён из рендереров. Ссылка из описания награды в атласе ведёт к списку миссий.

Проверено в Codex iab: реальное главное меню `/?review=home&lang=ru` с отдельным временным профилем → Миссии → След Ловчего → первая комната, без дополнительного подтверждения.

- 360×640: диалог списка 344×624, горизонтальное переполнение 0.
- 390×844: диалог списка 374×828, горизонтальное переполнение 0.
- 1280×720: главное меню и мир 1280×720; диалог списка 389×704, горизонтальное переполнение 0.
- На всех трёх размерах выбор первой миссии запускает комнату 1. Остальные четыре миссии закрыты на новом профиле.
- Проверены возврат в меню и прокрутка списка до пятой миссии. Переполнение кнопок не обнаружено.
- 11/11 существующих тестов mission-ui-regressions и mission-unlocks прошли.
- Проверка синтаксиса и Vite build в отдельный временный каталог прошли.
