## Автоматическая проверка

Команда: `node --import ./temp/creature-continuity/register.mjs --test --test-skip-pattern='every catalog item' tests/equipment-mounts.test.mjs`.

Результат: 3 теста PASS. Проверка креплений охватывает 910 сочетаний семи тел, 13 типов оружия, пяти типов ног и штатной/шестиногой конфигурации. Проверка соединений расширена с семи стандартных тел до 11 сочетаний тела и визуального варианта (восемь разных GLB) в трёх фазах выноса рук: всего 33 позы. Подтверждены загрузка выбранного варианта, начало приводов внутри закрытой оболочки, контакт с подвижным креплением и неизменный масштаб жёстких деталей.

Отдельный тест полноты каталога исключён: ранее выявлен отсутствующий в реестре `repairGland`, не относящийся к креплениям. Общий PASS всего проекта не заявляется. Сборка заново не запускалась: производственный код не менялся.
