# Ворота с зеленью и ржавчиной

Латунные рёбра и болты удалены из общей модели ворот миссий и логов. На металле добавлены пятна коррозии, у основания — следы сырости. Ветви с листьями закреплены на поверхности каждой половины и не пересекают центральный проход при открытии. Общая керамическая текстура сохранена.

Проверено в игровом маршруте логов, размеры 390×844, 360×640 и 1280×720. Итоговые снимки: gate-390.png, gate-360.png, gate-wide.png. На финальной загрузке ошибок и предупреждений WebGL нет.

15 профильных тестов ворот и миссий прошли. Проверочная JS/CSS-сборка Vite в temp/gate-ivy-build прошла; пакет игровых ассетов повторно не пересобирался.
