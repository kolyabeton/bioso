Проверено 2026-09-07 во встроенном браузере Codex, http://127.0.0.1:5173/.
Реальный маршрут: Survival → стартовая сборка → Seed Machine Gun → Start.
Без выдачи предметов, изменения HP или подмены игрового состояния.

- Пустой слот открывает настоящую сборку. Детали оружия доступны в сборке.
- Скриншоты сохранены и визуально просмотрены. Интерфейс использовал установленный английский язык; добавлены обе локализации состояния.

Общий запуск: 399 тестов, 11 ошибок. Два ожидания старой дальности исправлены и перепроверены целевым запуском.
