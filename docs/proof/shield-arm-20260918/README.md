# Отдельная рука «Щит» — 18 сентября 2026

`shieldArm` использует существующую модель `arm-shield.glb`, базовый вес 50. Защита от фронтальных снарядов в секторе 120°: 30% / 60% / 80% для одного / двух / трёх щитов; ранг и улучшения защиту не меняют. Урон тарана по рангам: 25 / 33 / 41 / 49 / 57, базовый цикл 5 секунд. Единственное улучшение — урон, +12% за уровень, предел 20.

Достижение «Против щита» считает 30 убийств щитоносцев игроком или спутниками за всё время. На 30-м убийстве стандартная однократная награда открывает предмет и выдаёт экземпляр.

## Актуальный интерфейс

Старый отдельный экран «Деталь», его дополнительные экраны свойств и снятия, действия, стили и проверочные привязки удалены. Не использовать его для показа игры. Карточки сборки открывают существующий инспектор `item-inspector`, а не отдельный экран.

Пять снимков старого экрана убраны из проекта в Корзину. Актуальные снимки инспектора: `inspector-360.png`, `inspector-390.png`, `inspector-wide.png`.

## Проверка удаления

- 48 проверок контракта параметров, инспектора, щита и отсутствия старого экрана прошли.
- Сборка приложения прошла в отдельной временной папке, без перезаписи поставки.
- IAB, без звука: `review=isaac&weapon=shieldArm&screen=assembly&sound=0&lang=ru`. Открыт установленный щит через реальную карточку крепления; улучшение изменило урон 25→28, защиту не изменило, биомасса уменьшилась 2000→1988. Закрытие возвращает к сборке.
- Размеры 360×640, 390×844, 1280×720: инспектор шириной 340 px, горизонтального переполнения нет. Кнопки действий высотой 44 px, закрытие — 48 px. На компактном экране свойства прокручиваются, действия остаются доступными.
- Бывший проверочный маршрут щита возвращает сборку без старого попапа; бывший общий маршрут возвращает главное меню.
