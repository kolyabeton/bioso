# Исправление пальцев ног — 2026-09-13

По замечанию пользователя заменены длинные загнутые когти у пяти механических ног: беговой, универсальной, панцирной, пружинной и роевой. Иконки показывают короткие механические пальцы с широкими тупыми концами.

Новые варианты `leg-*-icon-v2`: два передних пальца с двумя фалангами и индивидуальными узкими осями, плоские опорные площадки, короткая задняя опора. У панцирной ноги фаланги шире; у пружинной, панцирной и роевой — керамические накладки. Укорочена чрезмерно широкая ось голеностопа. Сохранены предыдущие GLB, верхняя конструкция ног, ключи предметов и сокеты. Руки и корневая нога не перегенерировались.

Переиспользованы существующие геометрические элементы генератора: скруглённые панели, цилиндрические оси, кольца и болты. PBR-карты остаются побайтово исходными из `leg-worker.glb`; UV-окна прежние. Новые текстуры не создавались.

Генерация: `node scripts/asset-kit/limb-icon-parity.mjs --legs-only`.

Проверки: 20 целевых тестов PASS (PBR/UV, GLB, бюджет полигонов, крепления на всех корпусах, положение стоп относительно земли, шесть ног и роевое оборудование). `npm run build` PASS. В iab осмотрены пять пар «иконка / модель», крупные планы стоп и сборка с шестью разными ногами на реальном маршруте игры при 390×844.
