# Интеграция сооружений секретов v2

Подключены мембрана, плита и питомник из `public/assets/kit/secret-*-v2.glb`; старые файлы сохранены. Общие габариты игровой сцены не менялись. Нейтральные поверхности не перекрашиваются золотой подсветкой; награда получает отдельный ореол после открытия.

В survival создаются 9 или 10 секретов: 3 каждого типа плюс случайный десятый. Сначала размещаются большие события, затем секреты, чтобы не потерять испытания из-за занятых площадок.

## Проверки

- `tests.log`: 3 новых теста, включая 100 seed, детерминизм, проходимость, минимальную дистанцию 32 м, сохранение 17 публичных событий, целостность GLB и материалов.
- `build.log`: производственная сборка прошла, 130 333 791 байт при лимите 500 000 000. Это снимок общей рабочей директории; в ней одновременно есть другие изменения.
- `activation-tests.log`: 4 проверки существующих активаторов и совместимости старой карты прошли.
- `activation-browser.json`: четыре проверки в Codex IAB. Начальное состояние `ready`, без врагов; обычная автоатака перевела каждый объект в `reward`: кислота, электрическая рука, бур и таранный щит.
- `baseline-tests.log`: до этих изменений уже падали старые проверки количества/уровней событий и PNG-спрайтов. В их прежней формулировке они не являются зелёным полным набором тестов проекта. Условия остальных событий не переписывались для подгонки этих проверок.

Альтернативные активаторы не внедрены: обсуждается явное взаимодействие возле сооружения с проверкой подходящего модуля/навыка и возможной оплатой биомассой. Цена и новый расход ресурсов не назначались без решения по механике.
