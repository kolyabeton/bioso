# Сучкорез: третий удар

Точка сбора — конец текущей игровой дальности атаки, а не поверхность героя. Обычные враги перемещаются максимум на 5 м, элиты — на 1 м; боссы не перемещаются. Цикл независимый для каждой руки; эхо не продвигает его и не прерывает основную анимацию.

Маршрут: `/?review=enemies&fixture=whip-pull&sound=0&capture=1&captureSeconds=5`. Это явно обозначенная DEV-сцена на настоящем игровом canvas: три обычных врага, элита и босс, первый удар заранее подготовлен как третий. Босс расположен за группой, чтобы его полоса здоровья не закрывала стяжку.

Проверены размеры 360×640, 390×844 и 1280×720, сборка, описание и границы инспектора. Запись `attack-390.mp4` сделана через canvas.captureStream; `sequence.png` содержит извлечённые кадры этой записи. Файлы source-hashes.json фиксируют исходники проверенной версии.

23 профильные проверки прошли: whip-pull, whip-vfx, melee-animation, item-presentation-contract. Production-компиляция Vite прошла (финальная компиляция без копирования public, предыдущая — с public). Расширенные проверки выявили ошибки вне этой правки: ожидание разброса дробовика .09 против текущего .1; стартовая установка открытого щита возвращает pistol вместо shieldArm. Эти проверки не заявляются как пройденные.
