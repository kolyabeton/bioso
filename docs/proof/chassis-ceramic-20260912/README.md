# Маточник, Гекатон, Бастион — корпуса и общая керамика

12 сентября 2026. Эта проверка заменяет предыдущие варианты Бастиона и Гекатона из `chassis-silhouettes-20260912`.

- Маточник: отдельный сегментированный горизонтальный корпус, боковые закрытые камеры симбионтов, поперечные латунные рёбра. Иконка `public/assets/ui/items/broodmother-v1.png` — прямой снимок изолированной новой 3D-модели, а не новая нейрогенерация или старый слот клешни.
- Гекатон: узкий высокий центральный корпус, три пары выступающих гнёзд. Силуэт сверялся с первой ячейкой второго ряда исходного атласа.
- Бастион: широкий вертикальный броневой щит, нижний ряд четырёх гнёзд; сверялся с третьей ячейкой первого ряда. Бывшая почти горизонтальная плоская форма отменена.
- Общие материалы: все восемь корпусов и опоры используют источники `CHASSIS_MATERIALS`. Керамика переиспользует существующую `public/assets/ui/materials/ceramic-worn-v1.jpg`, латунь и внутренний металл — прежние карты патины и ржавчины. Новых текстур не генерировалось. Общие варианты материалов корпусов используют те же объекты карт, добавляя вершинный износ; опоры не получают отсутствующий у них атрибут цвета.
- Добавлены затемнённые сколотые края, тонкие трещины и открытые металлические участки оболочек. Геометрия/материалы переэкспортированы во все `body-*-v3.glb`, стабильные идентификаторы сохранены.
- Исправлен сдвиг атласа после добавления новых ключей каталога: координаты 25 старых иконок теперь независимы от новых предметов. Новые ключи Маточника/роевых предметов сохранены.
