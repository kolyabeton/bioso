# BIOSO — новые корпуса и керамические шарниры

Семь новых цельных GLB построены по силуэтам существующих игровых иконок. Иконки сохранены. Это новые 3D-интерпретации, а не точная реконструкция каждого скола исходной иллюстрации.

## Что изменилось

- У каждого типа один стабильный корпус: Странник — овальный; Ловчий — узкий; Бастион — широкий; Химера — вытянутый и суженный снизу; Корнеход — округлый с мхом; Гекатон — продолговатый с несколькими рядами боковых гнёзд; Реактор — широкий верх и крупная центральная оптика.
- Старый сохранённый `visualId` и принадлежность комплекту больше не подменяют тип корпуса. Исходные GLB сохранены для старых противников; модели героя используют новые `body-<type>-v3.glb`.
- Убраны добавочная голова, шейный цилиндр, выпирающие подложка и таз старой сборки. Под керамическими панелями новых тел есть собственная замкнутая оболочка.
- Шарниры меньше: белые керамические щёки и кожух, латунные обоймы и крепёж, ржавый внутренний механизм. Керамические манжеты и детали шарнира сохраняют длину при выдвижении оружия.
- Руки придвинуты к поверхности своего корпуса. На широких телах средняя пара дополнительных ног вынесена из брони. Приводы начинаются внутри новой оболочки. Изменение посадки относится к визуальной модели героя; раскладка противников остаётся прежней.

## Исходники

Генератор геометрии: `scripts/asset-kit/chassis-v3.mjs`; профили силуэта: `src/chassis-profiles.js`; общие материалы: `src/creature-materials.js`. Новые GLB находятся в `public/assets/kit/` и зарегистрированы в его manifest.

Керамическая текстура сгенерирована встроенным imagegen с главным стилевым референсом. Полный промпт, метод и исходное изображение сохранены в `docs/art/chassis-v3/`; рабочая текстура — `public/assets/textures/chassis-ceramic-v3.png`, 512×512. Она встроена в новые GLB и используется на шарнирах.
