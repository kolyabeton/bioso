# BIOSO — соединения по сгенерированному референсу

Референс: `docs/art/creature-joints-v2/reference.png`. Генерация выполнена встроенным image_gen с каноническим `biomecha-style-master.png`; полный промпт сохранён рядом в `prompt.md`.

В 3D перенесены утопленный подшипник, вилка с фасками и центральным окном, фланцы с шестью крепежами, поперечные крышки оси, боковой гидроцилиндр, защищённый кабель и керамический кожух. Добавлены умеренная патина, микрорельеф металла и светлые обработанные кромки. Удалена прежняя последовательность толстых колец. Шарнир сохраняет постоянные пропорции; выдвижение руки компенсирует внутренний шток.

Геометрия едина для героя и сборных противников. Три фиксированных материала/геометрии шарнира переиспользуются; у противников используются пять общих пулов конструкции (корпус, шток, три поверхности шарнира). Исходные GLB, слоты, характеристики и боевые дистанции не менялись.

Проверка:
- 32 профильных теста PASS (`focused-tests.log`), включая все корпуса, варианты конечностей и шесть ног, непрерывность соединения и неизменный масштаб деталей при выдвижении рук, инстансы 100 противников.
- Vite production compilation PASS (`build.log`), результат в `temp/creature-continuity/build`; публикация не выполнялась.
- Реальная сборка `http://127.0.0.1:4193/?review=assembly&variant=stress&lang=ru`: 360×640, 390×844, 1280×720. Диалог в широком окне сохраняет ширину 389 px.
- Реальный бой `?review=body-combat&lang=ru`: нажата «Показать атаки», просмотрены активная атака и возврат в нейтральное положение (`combat-a-390.png`, `combat-b-390.png`).
- Реальные противники `?review=enemies&fixture=tactics&lang=ru`: `enemies-390.png`.
- `joint-closeup-390.png` показывает именно геометрию из игрового шарнира крупно в диагностической сцене; `hecaton-390.png` — полный боец. Эти кадры дополняют реальные игровые маршруты.

Как и в предыдущем прогоне, две посторонние проверки (полнота каталога для repairGland и ожидание здоровья финального босса) исключены из профильного набора. Полный набор тестов проекта не объявляется зелёным. Применён локальный Node CSS import hook из `temp/creature-continuity/register.mjs`.

Рабочая вкладка закрыта, viewport сброшен. API не позволил закрыть отдельную вкладку с ошибкой остановленного старого сервера 4191 из-за запрета доступа к служебному data URL.
