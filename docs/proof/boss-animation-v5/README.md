# BIOSO — анимации пяти боссов, v5

Проверено 8 сентября 2026 в Codex in-app browser. Исходные одобренные Blender-модели сохранены. В игровые GLB добавлена механическая иерархия бедро → колено → стопа и отдельные шарниры боевых органов. Геометрия каждого босса — около 70 тысяч треугольников, 16–25 mesh-объектов. Сборщик экспорта: `scripts/asset-kit/bosses_animation_v5.py`; метрики: `output/boss-animation-v5/manifest.json`.

## Движения в игре

- Ловчий: попеременные шаги, приседание, подъём клинков, поджатые ноги в рывке и взмах.
- Левиафан: медленная тяжёлая походка, наклон корпуса, движение пресса и вентиляционных секций.
- Собор: подготовка и удар корнями, наклон семенных колоколов при касте. Сам босс неподвижен по правилам боя.
- Сборщик: походка, разведение манипуляторов при копировании оружия, движение оптического диска в зеркальной стойке.
- Пастырь: парение со сложенными ногами, раскрытие улья и выпуск дронов, посадка и удары передними когтями во второй фазе.

Это процедурная анимация сочленённых деталей с IK, не запечённые скелетные Blender-клипы. Ходьба зависит от фактического перемещения, атаки — от боевых таймеров. Презентация не меняет состояние боя. Пауза/заморозка сохраняют позу; уменьшение движения снижает амплитуды, сохраняя предупреждения.

## Проверка

68/68 профильных тестов: `boss-animation`, `boss-model-view`, `mission-bosses`, `mission-unlocks`, `enemy-attack-animation`, `game`. Проверяются реальные поставляемые GLB, длины IK-звеньев, изгиб коленей, отрыв стоп, положение полной геометрии относительно земли при ударах и рывке, боевые органы, неподвижная поза на паузе/заморозке и отсутствие изменений боевого состояния. Лог: `output/boss-animation-v5/tests.log`.

Свежие acceptance и production сборки проходят; логи `output/boss-animation-v5/build.log` и `production.log`. Первоначальная попытка сборки попала на временно несогласованный импорт экрана достижений из параллельной работы; после его исправления сборки повторены успешно.

Все пять маршрутов проверены при 360×640, 390×844 и 1280×720: 15 случаев, без горизонтального переполнения, все модели и суставы загружены, ошибок ассетов нет. На широком экране сцена имеет ширину 405 px. Результаты: `viewports.json`, снимки `{mission}-{width}.png`. Проверка паузы: `pause.json`; диагностика боевых действий: `motion-checks.json`. Снимки FPS — только локальные показания, не гарантия производительности на телефонах.

## Видео

`all-boss-animations.mp4`: 48 секунд настоящей записи WebGL canvas через MediaRecorder, шесть последовательных фрагментов по 8 секунд:

| Время | Босс | Отдельный файл |
|---|---|---|
| 00–08 | Ловчий | garden.mp4 |
| 08–16 | Левиафан | quarantine.mp4 |
| 16–24 | Собор | core.mp4 |
| 24–32 | Сборщик | nursery.mp4 |
| 32–40 | Пастырь, полёт | mother-flight.mp4 |
| 40–48 | Пастырь, наземная фаза | mother-ground.mp4 |

MP4 перекодированы из исходных WebM; все файлы целиком декодированы ffmpeg без ошибок (`video-validation.json`). Выборочные кадры просмотрены. Запись canvas включает мир, модели и эффекты; DOM-интерфейс в неё не входит и проверен отдельными скриншотами.

Начальное условие: `?review=mission-boss&mission=...` — проверочный вход в последнюю комнату настоящей миссии с очищенными предыдущими комнатами, неуязвимым героем без оружия. ИИ, предупреждения, атаки, перемещение и дочерние цели настоящие. Это проверка боя с боссом, а не запись прохождения всех 25 комнат. Наземная фаза Пастыря включена уничтожением трёх узлов через обычный обработчик урона.

Локальный сервер записи: `scripts/boss-animation-proof-server.mjs`; принимает только пять имён миссий и сохраняет видео в этот каталог. Для повторения: сначала acceptance-сборка в `output/boss-animation-v5/acceptance`, затем запуск сервера, открытие маршрута и кнопка Record 8s. Порт 5291 должен быть свободен.
