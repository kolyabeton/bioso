# Основная оптимизированная сборка BIOSO

Итог: **98 829 048 байт**, 524 файла. Полный комплект меньше 100 000 000 байт.
Основной `npm run build` выпускает эту версию в `dist/`; отдельного lite-издания нет.
Исходные 304 ресурса сохранены, музыка не сокращалась.

## Автоматические проверки

- [Размер](size-report.json): учтены код, все ресурсы, манифест, общие текстуры и лицензии.
- [Проверка файлов](asset-verification.json): 101 GLB, 174 изображения, 19 аудиофайлов;
  исходные хеши не изменились. Геометрия и направление треугольников сохранены,
  карты нормалей и свойств материалов совпадают по декодированным пикселям.
- [Браузерная проверка](browser-assets.json): все 101 модель, 174 изображения и
  19 аудиофайлов реально декодированы в Codex in-app browser. 92 модели игрового
  набора загружены штатным `loadModel`; 9 исторических — тем же GLTFLoader/Meshopt.
  Ошибок и резервных моделей нет. Аудио проверено декодированием, а не прослушиванием.
- [Тесты оптимизации](optimization-tests.log): 6/6 PASS, включая точную границу
  100 МБ, вложенный CSS-импорт, динамические URL, прозрачность и сохранность модели.
- Полный набор: 620 тестов, 595 PASS, 25 FAIL. До изменений было 25 FAIL;
  [сравнение](test-comparison.json) не выявило новых падений. Это исходные ошибки
  игрового проекта; общий тестовый набор не объявляется зелёным.

## Проверка игры

Production-версия открыта через обычное меню: «Survival» → «Start», проверены
работающий таймер, отображение моделей и пауза. Снимок:
[production-survival-360.png](production-survival-360.png).

Для точного сравнения использованы существующие review-маршруты в acceptance-
сборках с исходными и оптимизированными ресурсами. Это реальные игровые экраны
и рендерер с фиксированными начальными состояниями, не отдельные макеты.
Эти проверки не заменяют длительное прохождение или тесты на физических телефонах.

У босса garden выполнено действие «Attack»: штатный бой перешёл в рывок,
модель `boss-mercury-hunter`, ошибок загрузки нет. В способностях выполнен выбор
усиления, в сборке открыта деталь. Подписи действий проверены измерением:
[360×640](button-labels-360.json), [390×844](button-labels-390.json) — одна строка,
без переполнения.

Четыре биома открыты существующим `review=forest-border`: `west` — gardens,
`east` — forest, `se` — city, `south` — scrapyard. При seed 20317 соответствие
подтверждено через реальный `world.tileAt`. [Сводка сцен](runtime-summary.json)
содержит измерения, состояния моделей и отсутствие ошибок ресурсов.

Воспроизведение: `npm run build -- --with-acceptance`, затем
`node scripts/asset-build/proof-server.mjs`. Оптимизированные маршруты — порт 5274;
`/__asset-check.html` запускает проверку всех ресурсов. Для исходного сравнения
нужна Vite acceptance-сборка оригинального `public/` в `temp/original-acceptance`;
она обслуживается на порту 5275. Проверочные серверы и временные исходные сборки
не входят в размер или содержимое основной игры.
